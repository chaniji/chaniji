## Why we need this

The simplest thing to print is fixed text. No variables, no logic.

## The idea

A string literal is text wrapped in quotes: `"hi"`, `'hi'`, or `` `hi` ``.

```ts
console.log("hi"); // prints: hi
```

## How it connects

This is the most basic input you can hand to `console.log()` (node A).
